--------------------------------------------------------------------------------

5. HOW TO GET explain() DATA (Node driver)
--------------------------------------------------------------------------------
With the official driver you can do, for example:
  const coll = db.collection("businesses");
  const explain = await coll.find(filter).sort(sort).limit(n).explain("executionStats");
  // read: explain.queryPlanner.winningPlan   (look for stage COLLSCAN / IXSCAN,
  //       and inputStage chains), and explain.executionStats
  //       (executionTimeMillis, nReturned, totalDocsExamined, totalKeysExamined).
For aggregation scenarios use coll.aggregate(pipeline).explain().
Normalize the nested winningPlan into a simple { stage, indexName, usedIndex }
summary on the server so the browser gets clean JSON (never the raw huge object).
Measure wall-clock time server-side with performance.now()/Date.now() around the
actual query run (separate from explain).
